Privacy Policy

Last updated: October 2, 2026

This policy covers this website and Reality Got Weird Publisher, a private TikTok API client used only by the owner of the @reality.got.weird account to post that account's own original videos.

This website

This site has no accounts, no forms, no cookies and no analytics. Video thumbnails load from YouTube's image servers.

What the publisher accesses

With the account owner's explicit authorization, the app uses TikTok Login Kit and the Content Posting API under the scopes user.info.basic and video.publish. It reads the authorizing creator's basic profile and posting settings to build a valid post, and uploads video files the owner created. It does not read, collect, store, sell, or share any other person's data, any viewer data, or any analytics.

Storage

OAuth tokens are stored only in the macOS Keychain on the owner's own computer. They are never transmitted to any third party, written to source control, or logged.

Retention and deletion

Tokens are deleted by removing them from the local Keychain. Access can be revoked at any time in TikTok → Settings → Security & permissions → Manage app permissions.

Children

Neither the site nor the app is directed at children, and neither collects data from anyone.
